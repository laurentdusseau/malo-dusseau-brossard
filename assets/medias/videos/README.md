# Rushes highlights (autoplay sous le hero)

## Durée recommandée
**10 à 15 secondes** par clip (idéal **12 s**).

- Muet, boucle, démarrage auto (comme CR7)
- Trop court (< 6 s) : pas le temps de lire l’action
- Trop long (> 20 s) : lourd en data / mobile, autoplay moins fluide

## Format
- **MP4 H.264** + audio désactivé (ou piste silencieuse)
- Carrousel plein cadre (`object-fit: cover`) : **16:9** ou **9:16** acceptés (idéal **1080p**)
- Poids cible : **2–8 Mo** / clip
